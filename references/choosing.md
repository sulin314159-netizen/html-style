# 选型

产物（网页 / deck）不参与选型：先按内容选风格，再按风格卡的「网页模式 / deck 模式」落地。

## 按内容选

| 内容类型 | 首选 | 备选 | 理由 |
|---|---|---|---|
| 产品首页 / 工具页 | moneyai | deepseek | 纸感 + 单绿，最像真实产品，不像模板 |
| 长文 / 散文 / 阅读页 | moneyai 或 echo | — | 两者都重留白；echo 更暖，moneyai 更冷 |
| 编辑栏目 / 年轻品牌 | muse | gradient | 撞色卡片 + 手绘图案，有活力但不吵 |
| 一屏信息（发布会、年度回顾） | muse | openai | 1280×800 一屏舞台，适合“一屏讲完” |
| 开发者工具 / AI 产品 | deepseek | openai | 技术蓝 + 细边框 + 玻璃，可信 |
| 品牌大片 / 深色发布 | openai | deepseek | 黑底 + 大标题 + 渐变素材 |
| 中文 SaaS / 营销活动 | gradient | echo | 紫蓝渐变是中文产品的“安全牌” |
| 传记 / 纪念 / 家族叙事 | echo | moneyai | 纸色 + 暖光 + 书卷气 |
| 教育 / 课程 / 学院 / 知识付费 | goodpage | echo | 奶油纸 + 深青 + 居中排版，可信、不油 |
| 上台讲观点 | muse | frontend-slides / open-slide | 一屏舞台原生，适合观点与节奏 |
| 路演 / 汇报 | htmlppt-pitch | deepseek | 商务、信息密度高、翻页稳 |
| 作品集 / 设计分享 / 强个人风格 | open-slide | muse | 1920 自由画布，一页一个焦点 |

## 不要用

- **不要给技术文档用 muse**：撞色和手绘图案会干扰阅读。
- **不要给纪念类内容用 gradient**：紫蓝渐变太“营销”，情绪不对。
- **不要给正式汇报用 openai 黑底**：投影仪上黑底容易糊，除非现场可控。
- **不要在同一页混两种风格**：tokens 不兼容，混出来一定土。

## 用户没指定时怎么问

只问一句，给 2–3 个选项和理由，例如：

> 这页我建议走「纸感极简」或「暖纸书卷」：前者更冷、更像产品；后者更适合叙事。你想偏哪边？

不要一次抛 8 个选项。
