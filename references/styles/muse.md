# 活力编辑 · muse

来源：`E:\myagentdemo\muse\index.html`（一屏新闻前瞻，用户喜欢它的图案）
一句话：像一本会动的独立杂志，撞色、手绘、一屏讲完。

## Tokens

```css
:root{
  --paper:#fafbf3;
  --ink:#203c32;
  --muted:#435239;
  --lime:#dcf782;
  --lavender:#e4dcfc;
  --peach:#ffb879;
  --link:#7351aa;
  --dot:#78a52d;
  --white-90:rgba(255,255,255,.65);
  --radius:24px;
}
```

撞色纪律：一页只从 `lime / lavender / peach` 里选**两种**做卡片底色，其余用 paper / ink；彩色 SVG 图案的填充色算装饰，不占强调色名额。卡片高度由内容撑开，每张彩色卡至少 3 行（标签 / 数字 / 说明），不够就缩小或合并。

## 字体

- `"Segoe UI", "Microsoft YaHei", sans-serif`
- 标题 38px / 1.2，`letter-spacing:-1px`；副标 18px / 1.5
- 小标签 16px，字距 1px

## 版式

- 固定 1280×800 舞台，`transform: scale()` 适配；也可改成响应式单屏
- 1–2 块撞色卡（lime / lavender），按内容量决定：字少就两块甚至一块，不要硬凑三块，卡片内 padding 24–28
- 大数字 `01` `02` 放角落，作为叙述节奏
- 顶部 eyebrow + 大标题，底部一行说明

## 图案

- 手绘感插画必须**内联 SVG**（花瓣、球体、星芒），不要 emoji、不要外链图片
- 装饰点用 CSS 圆点（`--dot`），不要用字符

## 动效

- hover 轻微上浮 1–2px；卡片背景色可淡入
- 不做滚动动画

## 适用 / 不适用

- 适用：编辑栏目、年轻品牌、活动页、一屏信息、年度回顾
- 不适用：技术文档、严肃汇报、长文阅读

## 文字密度

低。每张卡 ≤ 40 字，一页 ≤ 120 字；deck 只放标签、数字、一句说明。超了就拆页，不要缩字号硬塞。

## 网页模式

- 把 1280×800 舞台改成响应式：≥960px 两列，以下单列
- 撞色卡片最多两块；手绘 SVG 缩成角落装饰
- 标题 38–56px；正文 16–18px

## deck 模式（原生）

- 1280×800 或 1920×1080 一屏；两列撞色卡 + 大数字 01/02
- 每页一个主题；图案放卡片角落，不压字
- 底部一行 disclaimer；键盘翻页 + 页码
## 反模式

- 灰扑扑、无图案、标准 SaaS 卡片
- 三种以上撞色
- 用 emoji 代替手绘图案
