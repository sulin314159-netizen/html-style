# 自由画布 · open-slide

来源：Open Slide 的 `deck-open-slide-canvas`（1920 画布自由 Deck，用户采纳）
一句话：锁死 1920×1080 画布，一页一个视觉重心，版式像写 React 组件一样自由排。

## Tokens（每个 deck 选一套，全程不改）

```css
/* 1. Sea Indigo（默认） */
--bg:#0a0e1a; --ink:#f5f5f7; --accent:#5ac8fa;

/* 2. Ash & Lime */
--bg:#f1efea; --ink:#161616; --accent:#c5e803;

/* 3. Mate Mocha */
--bg:#1a1411; --ink:#f5e9d6; --accent:#d97757;

/* 4. Pearl Rose */
--bg:#fdf6f3; --ink:#1a1015; --accent:#ff5d8f;
```

## 字体

- 西文：`'Inter Tight'`（display）+ `'Inter'`（body）；编辑感时用 `'Source Serif Pro'`
- 中文：`'Noto Sans SC'`（无衬线）或 `'Noto Serif SC'`（衬线），**不要混用**
- 数据/时间戳：`'JetBrains Mono'`
- 字号阶梯（px）：18 / 22 / 28 / 36 / 48 / 64 / 88 / 120 / 160 / 220

## 版式

- 每页 `1920×1080`，`transform: scale()` 适配，禁止溢出
- 内边距只用 96 / 128 / 160 三档
- **每页只有一个视觉重心**：一句金句、一个数字或一张图；不要两段平等文字
- 角落标记：右下 `№N/M`，左下 deck 标题
- 自由排布，但版式必须服务内容：封面 / 陈述 / 数据 / 三列 / 满版图，按内容选

## 文字密度

低。每页一句 + 一个数字或一张图；≤ 50 字。多一个字就删。

## 网页模式

- 把 1920 画布拆成响应式分屏：`100vh` 一节，每节一个焦点
- 深色底 + 单一 accent 不变；角落标记改成页脚小字
- 滚动时不做视差；每屏只留一个主张

## deck 模式（原生）

- 1920×1080 固定画布 + `←` `→` 翻页 + 角标
- 一页一个焦点；文字不超过 3 行
- 适合：作品集、设计/艺术分享、个人风格强烈的演讲

## 反模式

- 多色彩虹、emoji 图标、lucide/feather 通用图标库
- 一页两个平等论点
- 正文铺满整页
- 为了“自由”而每页换一种版式逻辑
