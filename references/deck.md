# Deck 规格

## 画布

- 1920×1080（16:9）或 1280×720；用 `transform: scale()` 适配窗口，居中。
- 默认一屏放得下；放不下时允许纵向滚动，不裁切内容。
- 每页一个 `<section class="slide">`，绝对定位叠放，只显示当前页。

## 翻页

- `←` `→` `↑` `↓` `Space` `PageUp` `PageDown`
- 滚轮：内容未溢出时翻页；溢出时先滚内容，滚到边缘再翻页
- 页码：右下角 `01 / 05`（mono 或小号无衬线），左下角 deck 标题
- 可选：`?slide=N` / `#/N` 深链，方便直接打开某一页

## 每页的内容纪律

- 一个观点。标题说结论，不说主题名。
- 标题 ≤ 2 行；要点 ≤ 5 条；正文 ≤ 3 行。
- 一页最多一个视觉重心（一句大字 / 一个数字 / 一张图）。
- 内容页至少三层：标题 / 一句支撑 / 信息块；死白 < 1/3。
- 一页放不下就拆页，不要压成“标题 + 一排小字”。

## 备注

```html
<aside class="notes">
  讲这里时停顿，先让他们看数字，再解释口径。
</aside>
```

或 `data-notes="..."`。备注不显示在页面上。

## 任何风格做 deck 的通用改造

网页 → deck 不是换皮，是改四件事：

1. **画布**：固定 16:9，`scale()` 适配窗口；默认一屏放得下，放不下时纵向滚动。
2. **字号**：标题放大 1.6–2.2 倍；正文 22–24px（按现场距离）。原生 deck 风格（frontend-slides / htmlppt-pitch）以各自卡里的字号为准。
3. **密度**：一页一个观点；网页的一屏内容拆成 2–3 页。
4. **交互**：键盘翻页 + 页码；网页的 hover / 滚动动效收掉。

## 各风格的 deck 微调

| 风格 | deck 气质 | 注意 |
|---|---|---|
| moneyai 纸感极简 | 安静的纸 | 留白更大，绿色只给结果值 |
| muse 活力编辑 | 一屏编辑（原生） | 两列撞色卡 + 大数字；图案缩到角落 |
| deepseek 技术蓝 | 白底技术分享 | mono 标签；一页一个结论 |
| openai 黑白剧场 | 黑场大片 | 巨大标题；渐变素材只做锚点 |
| gradient 渐变梦幻 | 营销发布 | 渐变只给关键词/数字，封面最多一处 |
| echo 暖纸书卷 | 叙事分享 | 引文页 + 章节页；少图表 |
| frontend-slides 纸墨编辑 | 叙事演讲（原生） | 衬线标题 + 发丝线；数字用无衬线 |
| htmlppt-pitch 柔和渐变 | 商务路演（原生） | 白底 + 渐变词 + metric 卡；内容页别扁 |
| open-slide 自由画布 | 作品集 / 设计分享（原生） | 1920 画布 + 单一 accent；一页一个焦点 |
| goodpage 书院暖光 | 课程 / 学院 / 知识分享 | 居中构图；teal / coral / gold 一页只用一个 |

各风格的详细规则在 `references/styles/<name>.md` 的「deck 模式」一节。## 自检

- [ ] 画布正确；放不下时能纵向滚动，没有被裁切
- [ ] 键盘翻页可用，页码正确
- [ ] 每页一个观点
- [ ] 标题不换行超过 2 行
- [ ] 内容页死白 < 1/3（按 20px 网格找最大连续纯白矩形，面积 / 页面面积 < 33%）
- [ ] 数字是 lining，`1` 不会被读成 `I`
- [ ] 没有 emoji / 装饰符图标
- [ ] 深色页不超过一半（投影场景）
