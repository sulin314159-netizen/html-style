# 质量自检

交付前逐条过。每一条都来自真实翻车，不是理论。

## 1. 不要随便放大单个中文字

**翻车**：把“公司不会消失”的“公”做成 drop cap，单独放大到 168px，结果像错字，也像海报贴错了位置。

**规则**：中文没有 drop cap 传统。单字放大只在三种情况成立：

- 品牌字 / 标志字（“回”“墨”）
- 章节序号（“壹”“贰”“03”）
- 口号的首字本身是独立概念（“慢”）

其他情况放大整句，或者放大一个短语。

**检查**：遮住被放大的字，整句还读得通吗？读不通就不该放大。

## 2. 数字必须是 lining，且不能和字母混淆

**翻车**：`12→1` 用 Cormorant Garamond 渲染成 `I2→I`，看起来像字母 I。

**规则**：

- 数据、页码、度量值：`font-variant-numeric: lining-nums tabular-nums;`
- 数据用无衬线（Inter / 系统 UI）；衬线只用于正文和标题，不用于数字
- 交付前把数字读一遍：`12` 会不会读成 `I2`，`10` 会不会读成 `IO`

**检查**：截图放大看 1、0、l、I 是否可区分。

## 3. 不用装饰符当图标

**翻车**：用 `❦` 做章节分隔，字体缺字后落到 fallback 字体，渲染成一个错位的红色图案。

**规则**：

- 图标一律内联 SVG 或纯 CSS（圆点、细线、方块、几何）
- 不用 emoji（📌 ✅ ❌）、不用 dingbat（❦ ☙ ✳ ❖）
- 分隔用 1px 线或留白，不用符号

**检查**：全页搜一遍，除正文标点外不应出现装饰性 Unicode。

## 4. 内容页不能“扁”

**翻车**：一页只有标题 + 三张小卡片，上下各空 40%，像没做完。

**规则**：

- 内容页至少三层：标题 / 一句支撑 / 信息块
- 纵向分布：`justify-content: space-between` 或 `center`，不要全部顶对齐再留一大片底白
- 自测：把页面缩到 50%，如果第一眼只看到“标题 + 一排小卡片”，就是扁
- 封面与收尾允许留白（可以超过 1/3），这条只约束内容页
- 色块/卡片同理：高度由内容撑开；一张彩色卡少于 3 行信息，就缩小或合并，不要靠拉大色块填空
- 反例：1280×800 里两张 300px 高的撞色卡，每张只有一个数字和一行字
- 补救顺序：加一句结论 → 加一条分隔线/数据 → 再加信息块；不要用无意义的装饰填

**检查**：内容页死白面积 < 1/3，且第一眼有明确的视觉重心。

- 区块数量不是 KPI：内容只有两件事就两块，别硬凑三块；不对称也可以好看。
- deck：标题 ≥ 屏高的 8%，一眼能读出主题；宁可拆页，不缩字号。
- 网页：每个 section 至少一屏高，不要“半屏内容 + 半屏空白”的夹生页。

## 5. 颜色

- 强调色只能一个；渐变类风格只允许卡里那条渐变
- 正文对比度 ≥ 4.5:1；大字（≥ 24px）≥ 3:1
- 不用纯黑 `#000` 做正文（openai 风格除外，它本来就是黑底白字）

## 6. 排版

- 中文正文行高 1.65–1.9；标题行高 0.95–1.2
- 标题与正文至少 2 倍字号差（只要求 h1/h2 对正文；小屏可降到 1.8 倍），否则没有层级
- 字距：中文标题用 0 或 +0.02–0.06em；负字距只给西文 display，中文正文不要调字距
- 一页最多两种字体（一个 display + 一个 body）

## 7. 交互与可达性

- `:focus-visible` 必须可见
- 所有可点击元素有 hover 反馈
- deck：`←` `→` `Space` 可用；页码正确
- 移动端：无横向滚动；字号不小于 14px（标签、注释也算）
- 响应式验收：至少截 320 / 390 / 768 / 1440 四个宽度，逐个看有没有贴边、溢出、字号过小

## 8. 去 AI 感

- 不用默认紫蓝渐变；只有 gradient、htmlppt-pitch 这两套渐变风格可以用
- 不用三张完全一样的卡片排一排；风格卡要求三张卡时，必须有信息差或结构差
- 不用 emoji 列表、不用“✨ 特性一 ✨”式标题
- 字数对风格：低密度风格写成大段 = 跑偏；高密度风格只放一句 = 空。按风格卡的字数预算检查
- 不用玻璃拟态，除非风格卡要求
- 文案不编数据；不确定的数字标“示意”
